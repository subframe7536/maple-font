# CJK Build

Maple Mono supports CJK character sets. Compared with V7, V8 greatly expands and improves its CJK coverage for Simplified Chinese, Traditional Chinese, Japanese, and Korean. CJK glyphs use a 2:1 width ratio with Latin characters to keep multilingual text and Markdown tables aligned; as a trade-off, the default CJK spacing is wider than in many other CJK fonts. See [this issue](https://github.com/subframe7536/maple-font/issues/211) for details.

| Locale | Coverage                                                                | CJK font source                                                                                     | Build output |
| ------ | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------ |
| CN     | Simplified Chinese, with common Traditional Chinese and Japanese ranges | [WenYuan Rounded SC](https://github.com/takushun-wu/WenYuanFonts)                                   | `CN`         |
| TC     | Traditional Chinese                                                     | [Chiron Go Round TC](https://github.com/chiron-fonts/chiron-go-round-tc)                            | `TC`         |
| JP     | Japanese                                                                | [Resource Han Rounded JP](https://github.com/CyanoHao/Resource-Han-Rounded)                         | `JP`         |
| KR     | Korean                                                                  | [Chiron Go Round TC](https://github.com/chiron-fonts/chiron-go-round-tc), filtered to Korean ranges | `KR`         |

For the exact Unicode ranges of each locale and the resulting file names, see [CJK Character Sets](./choose.md#cjk-character-sets).

## Enable CJK Builds

CJK fonts are not generated by default. Use the CJK build configuration to select one or more locales, static or variable output, and optional compact spacing:

- In [`config.json`](../config.json), set `cjk.locales.cn` / `jp` / `tc` / `kr` to `true`.
- On the command line, pass `--cjk <locales>`; repeat it or use comma-separated values, for example `python build.py --cjk cn` or `python build.py --cjk cn,jp`.
- Pass `--cjk-variable` (or set `"cjk.variable": true`) to persist CJK-extended output as merged variable fonts.

## Base Fonts

Enabling a CJK build downloads the required base glyphs from the [`cjk-base` GitHub Release](https://github.com/subframe7536/maple-font/releases/tag/cjk-base). Local base directories and ZIP archives are used first, then remote archives, and finally a rebuild from the original source fonts. See the [CJK source, configuration, generation, and cache guide](../scripts/cjk/README.md) for the full resolution order.

If a download fails, configure a [GitHub mirror](./build.md#github-mirror), or download the target `.zip` file and place it next to `build.py`.

## Nerd Font and Hinting

When Nerd Font is enabled (the default), CJK builds produce NF-CJK outputs. `--cjk-both` builds both NF CJK and non-NF CJK outputs. Set `"cjk.with_nerd_font": false` to exclude CJK entries from the Nerd Font profile.

Final static CJK fonts are not auto-hinted by default. Pass `--cjk-hinted` (or set `"cjk.use_hinted": true`) to auto-hint them.

## Narrow CJK Spacing

If only the CJK characters have **too much** spacing while Latin characters look correct, use the `cjk.narrow` build option or the `--cjk-narrow` command-line argument. This prevents the font from being recognized as strictly monospace.

See [#249](https://github.com/subframe7536/maple-font/issues/249#issuecomment-2871260476) for a preview and discussion.

- To change Latin character width as well, use the [`--width` option](./build-options.md#character-width).

## Scale Factor

Use `"cjk.scale_factor"` in `config.json` or `--cjk-scale-factor` on the command line to scale the glyphs of the selected CJK locales. The format is `<factor>` or `<width_factor>,<height_factor>` (`[<width_factor>, <height_factor>]` in `config.json`), for example `1.1` or `1.2,1.1`.

## Centered Full-Width Punctuation

Maple Mono supports the `cpct` feature to center full-width punctuation, which is common in Traditional Chinese; you can also enable `cv99` to force this behavior. See [#150](https://github.com/subframe7536/maple-font/issues/150) for details.

## Deprecated CN Options

The V7 `--cn` options are still accepted as deprecated aliases:

| Deprecated option   | Replacement                           |
| ------------------- | ------------------------------------- |
| `--cn`              | `--cjk cn`                            |
| `--no-cn`           | Remove `cn` from the selected locales |
| `--cn-narrow`       | `--cjk-narrow` when targeting `cn`    |
| `--cn-scale-factor` | `--cjk-scale-factor` when targeting `cn` |
| `--cn-both`         | `--cjk-both`                          |
